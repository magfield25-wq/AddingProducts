# 맥필드 상품등록 작업실

113개 상품의 상품정보 복사, 원본 이미지 열기 및 저장용 상품명 복사, 등록용 HTML 생성, PC/모바일 미리보기, 수동 등록완료 관리.

## GitHub Pages 활성화
Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save.

상품명은 임시 규격명이며 가격/기준코드는 엑셀 제공 후 연결 예정입니다. 현재 직접 입력 가능합니다.
작업 상태는 각 브라우저에 저장됩니다. 친구와 상태 이동 시 작업 백업/불러오기를 사용하세요.
사진은 원본 새 탭에서 우클릭 또는 모바일 길게 누르기로 저장하세요. 저장용 상품명을 복사해 파일명에 붙여 넣을 수 있습니다.
네이버 상세설명 최종 표시 여부는 네이버 상품등록 화면에서 확인하세요.
