# 사각 네오디뮴 자석 상세페이지 리뉴얼

원형 작업에서 확정한 방식으로 사각 자석을 별도로 진행한다. 원형 완성본은 수정하지 않는다.
기존 사각 상품자료 출발점: 저장소 square.html. 실제 데이터 및 상품 수량을 먼저 확인하고, 원형113개라는 수량을 다른 형태에 그대로 적용하지 않는다.
기준 작업실: https://magfield25-wq.github.io/AddingProducts/one/?v=12
기준 파일: 저장소 one/index.html (현재 호스팅된 단일파일). 이 파일은 상품 데이터와 복사용 HTML을 모두 포함한다. 원형 작업의 클라우드 전용 /workspace/scratch 경로에는 의존하지 않는다. 새 작업 환경의 경로를 사용한다.
유지할 사용자 요구:
- 일반HTML완성본과 스마트에디터ONE변환용을 구분한다. ONE에 실제변환되어 검증된 표구조를 사용한다.
- 제품제목은 회사명/제품명/사이즈3줄 가운데정렬, 충분히 큰 글자. 대표사진→CAD→제원표→흡착력 이미지/주석→취급주의 순서.
- N35등급, 흡착력은 제공된 해당형태 새계산값을 사용할 것. 원형값/도면을 재사용하지 않음. 단위중복/서식차이 검수.
- 후기24개, 앞6개, 나머지는 상품10개마다2개씩(상품수가 다르면 사용자와 배치확정). 원형리뷰를 사각리뷰로 오인해 넣지 않음.
- 후기2열 표, 사진/별점/제목/본문/작성자를 별도행으로 맞춤. 금색별. 텍스트왼쪽/위쪽정렬. 사진누르면원본.
- 상품명 아래줄 구매링크, 해당상품표와 가까이, 상품사이구분선/여백. 상품목록은 flat3column, 중첩표금지. 목록사진칸의 모바일공백은 허용.
- 남색제목/진회색본문/연두선/옅은회청배경. 강조는필요한곳만. 주석/주의사항23px불릿.
- 배송안내: 묶음배송,5만원이상무료배송,상점 https://smartstore.naver.com/hkn2024 .상품구매링크는실제상품등록번호대조.
- 상세설명 새이미지3장 URL은 원형 작업실에 포함. 공통설명 적용가능범위 확인 후 사용하고 형태별규격/전용내용오류방지.
- GitHub Pages호스팅, 상품검색/미리보기/HTML복사/TXT다운로드. 원형/기존메인화면보존, 별도경로사용.
- Safari미리보기 해결법: iframe referrerpolicy=no-referrer, srcdoc meta referrer=no-referrer, 미리보기이미지 referrerpolicy=no-referrer. Naver이미지GitHub리퍼러전달시403재현됨. 복사HTML과미리보기패치를분리.
- 버전별다른파일명. 기존파일덮어쓰기금지. 일반브라우저검증과실제ONE검증을구분. 검증하지않은것완료주장금지.
- 블로그비공개게시/URL수집자동화는별도프로젝트‘이미지 네이버 블로그’의‘블로그 url 가져오기’에서진행, 이쪽은제공주소를반영.
이 문서는 저장소에 게시된 인계 자료이다. 새 채팅의 로컬 경로에 없으면 origin/main에서 이 파일을 가져오거나 GitHub 원문 URL로 읽는다. 새 채팅이 자동 생성·전달된 것은 아니다.
